> **Статус:** внедренческая карта 55 узлов после изменений реестра коммитами `59ccb0c`,
> `26015f8` и серией решений о ночной охоте до `e485f41`.
> Триггеры и условия ниже сокращены для сверки; источником механики остаются
> [реестр квестов](../../../manual/design/chairman/quests.md#7-базовые-квесты) и
> `design.db`. Строки игрока лежат отдельно в [Эпохе I](../texts/development-quests-era-i.md)
> и [Эпохах II–III](../texts/development-quests-later-eras.md).

## Как читать

| Поле | Значение |
|---|---|
| **Линия** | `Ствол`, `Производство`, `Управление`, `Село и люди` |
| **Статус** | `Основной` — общий корпус; `Условный` — может не появиться по состоянию мира; `Необязательный` — отдельная выбранная ступень линии |
| **Предшественник** | Только реальная зависимость доступности или принятый порядок ветки. Знак `†` означает: порядок принят содержанием ветки, но прямо не назван в поле `opens` реестра |
| **Подача: готово** | Сцена или точная заготовка уже написана в RPG-мануале |
| **Подача: нужна** | Место для следующего текстового прохода; новая механика не предполагается |
| **Мир / событие** | Причина уже читается поведением жителей, видом юнита, письмом, алармом или игровым событием; отдельная сцена не нужна |

Все квесты можно убрать из тетради, ни один не блокирует механику. Необязательность в
матрице означает положение внутри ветки, а не отдельное правило отказа
([правила квестов](../../../manual/design/chairman/quests.md#3-правила)).

## Реальные последовательности

Эти зависимости должны проверяться как цепи, а не только как совпавшие темы:

```text
«Своя контора» → «Счетовод»
«Учить детей» → «Учитель»
«Разметить сеть» → «Пустить ток»
«Куда пойти вечером» → «Клуб» → «Дом культуры»
«Своя станция» ┬→ «Где ставить машины»
               └→ «Свой трактор»
«Спортплощадка» → «Большой футбол»
«Фельдшер в селе» → «Своя больница»
«Счетовод» → «По науке» → «Дать полномочия» → «Право на ошибку» → «Без председателя»
```

Зависимости со знаком `†` требуют отдельной проверки реализации: смысловой порядок
принят, но текущая строка `opens` не называет закрытие предшественника.

## Общие проверки поведения

| Случай | Ожидаемое правило | Статус опоры |
|---|---|---|
| Одновременно открылись несколько обычных квестов | В тетради не больше трёх, остальные ждут | Принято в правилах очереди |
| Переход эпохи открыл пакет | Эпохальные выдаются по одному | Принято в правилах очереди |
| Игрок отказался от необязательного узла | Продолжение ветки не рвётся, чужие награды не теряются | Принято в правилах веток |
| Игрок отказался от любого квеста | Запись больше не показывается, механика не закрывается, награда теряется | Принято в общих правилах |
| Аларм и квест совпали по теме | Аларм показывается, квест скрыт; очки начисляются только один раз | Принято в стыке с алармами |
| Квест выполнил автономный специалист | Закрывается по состоянию хозяйства, очки получает председатель | Принято в стыке с делегированием |
| Условие закрытия выполнено **до фактической выдачи из очереди** | Требуется решение: немедленное закрытие при выдаче либо снятие без награды | **В документах прямо не найдено** |
| Специалист сквозной ветки уехал до ошибки | Ветка ждёт следующего человека, получившего автономию в выбранной области | Принято содержанием RPG; требуется сверка хранения состояния |
| После ошибки автономию сохранили | Финальный узел ждёт своих условий | Принято содержанием ветки |
| После ошибки уровень снизили или отобрали | Финальный узел ждёт нового достижения автономии; дополнительной награды нет | Принято содержанием ветки |

## Следующий проход по матрице

1. Получить решение по заранее выполненному условию и зависимостям `†`.
2. Дописать помеченные сцены Эпохи I–II, начиная с учителя, фельдшера и первого
   трактора.
3. Написать три крупные сцены Эпохи III: техникум, больница, дом культуры.
4. Передать `boss` готовые дословные строки и список сцен для базы.
